批量图片裁剪工具
使用说明
开发者：无春夏
更新日期：2026年10月10日
============================================================

一、这个工具能做什么

在一张图片上确定矩形裁剪区域，再把同一文件夹中的所有图片，
按照完全相同的原图像素坐标批量裁剪。

适合仿真不同时间步导出的截图，以及其他尺寸、布局相同的图片。
所有成功处理的图片具有相同的输出宽度和高度，文件名保持不变。
原图不修改、不删除；每次结果都存放在新建的子文件夹中。

运行方式：双击“批量图片裁剪工具.exe”。
适用系统：Windows 64 位，建议 Windows 10 / 11。
无需安装 Python，无需联网。


二、第一次使用：按这几个步骤操作

1. 选择文件夹
   点击“选择图片文件夹”，选中原图片所在的文件夹。
   程序读取当前层的 JPG、JPEG、PNG 图片，不读取下级子文件夹。
   文件名按自然顺序排列，例如 1.png、2.png、3.png、10.png。
   界面显示图片数量、选区基准图片名称和原图尺寸。

2. 设置裁剪区域
   在预览图片上按住鼠标左键拖动，画出矩形选框。
   可以继续拖动选框的位置和大小，也可以直接输入输出宽、高。

3. 检查结果
   查看原图坐标及输出尺寸，点击“预览裁剪结果”确认效果。
   确认后关闭预览窗口。

4. 批量裁剪
   点击“开始批量裁剪”，等待尺寸检查和裁剪进度完成。
   完成窗口会显示成功数量、跳过 / 失败数量，以及输出位置。
   点击“打开结果文件夹”查看图片。


三、用鼠标调整选框

画出矩形：在图片上按住左键拖动，再松开。
移动矩形：按住框内拖动，宽度和高度保持不变。
调整大小：拖动四角的小方块，或拖动四边的小方块、边框。
重新画框：在框外的图片区域拖动，或点击“重新选择区域”。

未锁定比例时：
拖动四角可同时改变宽、高；拖动单边只改变对应方向。

锁定比例时：
拖动四角或四边，宽、高按锁定比例同步变化。
拖动角点时对角固定；拖动边时对边中点固定。

选框限制在图片范围内。宝蓝色边框和框外轻微变暗的效果，
只用于突出当前选区，不会写入裁剪结果。开发者署名也不会写入图片。

大图片在界面中会等比例缩小显示，但裁剪始终使用原图像素坐标。
调整窗口大小不会改变已经确定的裁剪区域。


四、直接输入精确的输出尺寸

“输出尺寸”中的“宽”和“高”既用于实时显示，也可以直接编辑。
单位是原图像素，标记为 px。

不限制比例时：
1. 取消勾选“锁定纵横比”。
2. 输入需要的宽度和高度，例如宽 1200、高 800。
3. 按回车或点击“应用尺寸”。
4. 如需调整位置，在框内拖动，再预览确认。

锁定比例时：
以最后修改的那一边为准，另一边会按比例自动计算并取整。
例如锁定 16:9，输入宽 640，应用后高度为 360。
如果宽、高都需要自行指定，请先取消比例锁定。

应用尺寸时，程序尽量保留选框左上角的位置。
如果右边或下边空间不足，会平移选框，以容纳指定的准确尺寸。
如果还没有选框，会在图片中央创建指定尺寸的矩形。

只能输入大于 0 的整数。输入无效或尺寸超过原图时会提示，
不会为了适应图片而擅自缩小您输入的尺寸。

鼠标调整选框后，输入框会同步显示新的实际宽、高。
预览、保存区域或开始裁剪前，也会自动应用尚未提交的尺寸输入。
建议输入后先点击“应用尺寸”，确认选框位置，再进行下一步。

注意：修改这里的数值，是改变裁剪范围，不是把图片内容缩放到指定尺寸。


五、使用固定比例：4:3、16:9、1:1

在“锁定纵横比”旁的下拉框中，可以选择：
  当前选框比例
  4:3
  16:9
  1:1

使用预设比例：
1. 先选择图片文件夹。
2. 在下拉框选择需要的比例，例如 16:9，程序会自动勾选比例锁定。
3. 在图片上拖动画框，再调整位置和大小。

如果已经有选框，选择预设比例会调整现有选框：
保持选框中心位置，尽量保持宽度；边缘空间不足时等比例缩小。

保留自己画出的比例：
先画好选框，将下拉框设为“当前选框比例”，并确认已勾选锁定。
程序会记住当时的宽高比例，之后可等比例放大或缩小。

取消“锁定纵横比”后，可以自由调整宽、高。
如果下拉框仍选着 4:3、16:9 或 1:1，再次勾选会重新套用该预设。

锁定状态下，在框外重画会沿用锁定比例。
点击“重新选择区域”则会清空选框、解除锁定，并恢复“当前选框比例”。

图片必须按整数像素裁剪，因此比例计算后的宽、高需要取整。
实际比例可能有轻微的像素取整误差，但不会因反复调整而累积比例漂移。


六、多个文件夹复用同一个固定区域

如果多个文件夹的图片原始尺寸和内容布局相同，可以只设置一次区域。

1. 在第一个文件夹中调整好位置、宽度、高度和比例选项。
2. 点击“保存裁剪区域”。
3. 切换到另一个文件夹。
4. 如果原图尺寸相同，程序自动恢复保存的区域，确认后即可批量裁剪。

保存的是原图坐标、基准原图尺寸，以及比例锁定状态和比例。
因此复用时不仅宽高一致，裁剪位置也一致。
关闭程序、下次重新打开后，保存的区域仍然有效。

“保存裁剪区域”：用当前设置更新保存的区域，目前只保存一套。
“应用已保存区域”：恢复之前保存的位置、尺寸和比例状态。

临时拖动选框、修改尺寸，不会自动改掉已保存的区域。
只有再次点击“保存裁剪区域”，才会替换之前的设置。

新文件夹的原图尺寸不同时，不会自动套用或缩放保存的区域，
界面会提示重新框选；原来保存的设置仍会保留。
如果图片布局发生变化，即使尺寸相同，也需要自行检查选框位置。


七、输出位置与文件名

输出保留原文件名和扩展名，方便与原图一一对应。
例如原图叫“0001.png”，裁剪结果仍叫“0001.png”。

原图片文件夹示例：
D:\CFD\Case1\
    0001.png
    0002.png
    裁剪结果\
        0001.png
        0002.png

每次都会新建一个结果子文件夹：
“裁剪结果”已存在时，依次使用“裁剪结果_2”“裁剪结果_3”……
不覆盖原图，也不覆盖之前的裁剪结果。

PNG 继续保存为 PNG，采用无损保存，保留透明度。
JPG / JPEG 继续保存为 JPEG，裁剪后使用高质量重新编码。
输出宽、高一致，但文件占用的 KB / MB 大小不一定相同。


八、异常图片与处理提示

开始时先检查图片尺寸，再逐张读取、裁剪和保存。
程序不会一次把整批图片全部加载到内存。

图片尺寸不同：跳过，不自动拉伸或缩放。
图片损坏、无法读取：跳过并记录原因，继续处理其他图片。
单张图片处理或保存失败：记录原因，继续处理其他图片。

完成窗口列出未处理文件的名称及原因，可以选中复制。
只有成功裁剪的图片才有对应的完整输出结果。
如果整个输出文件夹无法创建等任务级错误发生，会弹出错误提示。

第一张图片损坏时，会提示并改用自然顺序中第一张可读图片作为基准。
处理过程中请等待完成，再切换文件夹或关闭程序。

常见提示的处理方法：
“没有可处理的图片”：检查图片格式及是否放在所选文件夹当前层。
“请先选择裁剪区域”：画出矩形，或输入宽高并应用，或恢复保存区域。
“尺寸无效”：使用正整数，并检查所需宽、高是否超出原图。
保存区域没有自动恢复：检查是否保存过，以及原图尺寸是否完全一致。


九、把图片合成为 GIF 动图

裁剪完成后直接生成：
在完成窗口点击“用裁剪结果生成 GIF”，会使用本次成功裁剪的图片。

选择其他文件夹生成：
在主界面点击“图片转 GIF”，选择图片文件夹。
此入口直接合成所选文件夹中的图片，不使用主界面的裁剪框。
如果需要先裁剪，请先完成裁剪，再选择裁剪结果文件夹。

选择哪些图片生成：
GIF 窗口中显示图片列表，默认勾选全部图片，可直接点击“生成 GIF”。
每张图片左侧的方框以颜色表示选择状态：宝蓝色填充表示已选，
白色填充表示未选。点击图片行即可切换，颜色与已选数量同步更新。
点击“全选”可一键选中全部；点击“取消全选”可清空，再逐张选择。
点击列表中的一行即可勾选或取消该图片，也可以用方向键选中一行后
按空格切换勾选状态。图片较多时可滚动列表。
窗口显示“已选择 X / Y 张”，至少需要选择 2 张。
只会合成勾选的图片，播放顺序按文件名自然排序，与勾选先后无关。
裁剪完成后直接生成 GIF，也可以通过同一个列表挑选部分裁剪结果。

生成设置：
每帧时长默认为 100 毫秒，即每秒 10 帧。
数值越小播放越快；例如 200 毫秒为每秒 5 帧。
可输入 20～10000 毫秒，按 GIF 格式的 10 毫秒精度取整。

输出宽度默认 960 像素，会等比例缩小，原图较小时不放大。
输入 0 表示保持原尺寸。仅影响 GIF，不改变原图片或裁剪结果。
较小的输出宽度通常能减少文件体积，方便插入 PPT。

点击“生成 GIF”后等待进度完成，程序会按文件名自然排序合成，
例如 1.png、2.png、3.png、10.png。动图设置为循环播放。

GIF 保存在用于合成的图片文件夹中，文件名为“动画.gif”。
已有同名文件时新建“动画_2.gif”“动画_3.gif”等，不覆盖旧文件。
至少需要 2 张可读取且尺寸相同的图片；尺寸以第一张有效图片为准。
坏图片或尺寸不同的图片会跳过，并在完成后列出。
有效图片不足 2 张或生成失败时，不保留本次未完成的 GIF。

GIF 每帧最多 256 色，仿真云图的渐变可能有轻微色差；
透明区域统一使用白底。论文中的静态图片仍建议使用原裁剪结果。
生成过程中逐帧读取和编码，不会把整批图片同时加载进内存。

用于 PPT 时，将生成的 GIF 作为图片插入幻灯片，再进入幻灯片放映
检查播放效果。编辑状态下可能只显示静态画面。


十、发送给别人或更换电脑

运行只需要“批量图片裁剪工具.exe”。
建议把 EXE 和本“使用说明.txt”一起发送；若压缩成 ZIP，先解压再运行。
不需要发送源码、Python 环境或 build 等开发文件夹。
当前 EXE 为 Windows 64 位程序，不能直接在 macOS 上运行。

保存的固定区域不包含在 EXE 中，对方可以自行框选并保存。
设置文件位于当前 Windows 用户的：
%LOCALAPPDATA%\CFDImageCropper\saved_region.json

如需转移同一套设置，先关闭程序，再把该文件复制到另一台电脑的
对应位置；如果对方已有设置，请先备份，再替换。
更新或移动 EXE 不会清除同一 Windows 用户下已保存的设置。

常用流程
选择文件夹 → 框选 / 输入尺寸 / 应用保存区域
→ 确认比例和位置 → 预览 → 批量裁剪 → 查看结果
需要动图时：用裁剪结果生成 GIF → 设置时长与宽度 → 生成 GIF
