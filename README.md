# 批量图片固定区域裁剪工具

开发者：无春夏

Windows 本地桌面工具，使用 Python + Tkinter + Pillow。无登录、无服务器、无网络功能。

支持批量裁剪后合成 GIF 动图，用于 PPT 展示。

## 直接使用

完整中文操作说明：[使用说明.txt](docs/使用说明.txt)。分发给使用者时，只需要 EXE 和这份说明；无需下载源码、安装 Python 或配置开发环境。

前往 [下载页（Releases）](https://github.com/busterclun/cfd-image-cropper/releases/latest)，下载 Windows-x64.zip，解压后双击 **批量图片裁剪工具.exe**。此 EXE 可单独复制到其他 Windows 64 位电脑使用，不需要安装 Python。GitHub 的 Source code 压缩包只包含源码，不包含 EXE。

1. 点击 **选择图片文件夹**，选择原图片所在文件夹。
2. 在自动显示的第一张图片上，按住鼠标左键拖动框选。
3. 查看下方的原图坐标和输出尺寸。**按住矩形框内部拖动**可移动整个选区，宽高保持不变，选框不会移出图片。鼠标在框内会显示移动光标。
   **拖动四角、四边控制点或边框可改变选框大小**，对边保持固定，选框限制在图片范围内。四角可同时调整宽高，四边只调整对应方向。
   选框使用宝蓝色边框，框外区域轻微压暗（约 22%），框内保持原亮度；这些效果仅用于界面显示，不会写入裁剪图片。
   如需重画，在框外重新拖动画矩形，或点击 **重新选择区域**。
   如需等比例放大、缩小选框，先画好区域，再勾选 **锁定纵横比**，程序会记住当时的宽高比例。四角拖动固定对角，四边拖动固定对边中点并同步调整另一方向。取消勾选后恢复自由调整。
   也可以直接在比例下拉框选择 **4:3、16:9 或 1:1**，会自动锁定所选比例。尚未画框时，之后拖动即可画出该比例矩形；已有选框时，保持中心位置、尽量保持宽度调整到所选比例，边缘空间不足时等比例缩小。选择 **当前选框比例** 可重新锁定当前实际宽高比例。
4. 点击 **预览裁剪结果** 确认效果，然后关闭预览。
5. 点击 **开始批量裁剪**，等待完成提示，可直接打开结果文件夹。

“输出尺寸”的宽、高可以直接输入像素值，按回车或点击 **应用尺寸** 即可调整选框。鼠标调整选框时数值仍实时更新。未锁定比例时可分别输入宽、高；锁定比例时以最后修改的一边为准，另一边按比例取整计算。尽量保持选框左上角，靠近边缘时平移选框以容纳准确尺寸；未框选时在图片中央创建指定尺寸的选框。超出原图尺寸或输入非正整数会提示，不擅自缩小输入尺寸。预览、保存区域或开始裁剪前，也会自动应用尚未提交的尺寸输入。

结果自动保存在原文件夹下的 `裁剪结果`；已有同名文件夹时依次创建 `裁剪结果_2`、`裁剪结果_3`。程序不覆盖旧结果，也不修改、删除原图片。

## 多个文件夹使用相同的固定区域

1. 在第一个文件夹中框选并调整好区域，点击 **保存裁剪区域**。
2. 完成裁剪后，选择另一个文件夹。若原图尺寸相同，程序会**自动恢复保存的原图坐标**，位置、宽度和高度均保持一致，可直接批量裁剪。
3. 关闭后重新启动程序，保存的区域仍然保留；加载同尺寸图片时自动应用。
4. 临时拖动或调整选框不会改变已保存的区域，点击 **应用已保存区域** 可恢复。需要更新固定区域时，再次点击 **保存裁剪区域** 即可替换。

当前只保存一套固定区域，界面显示保存的坐标、输出尺寸和基准原图尺寸。若新文件夹的原图尺寸不同，不自动缩放或套用保存区域，界面会提示重新框选；之前保存的区域仍然保留。

保存区域时也会保存比例锁定状态和比例；旧版保存文件仍可使用，默认不锁定比例。锁定后在框外重画仍沿用该比例；点击“重新选择区域”会清空选框并解除锁定。由于输出必须使用整数像素，等比例调整时宽、高会各自取整，可能有不到 1 像素的取整误差；多次调整始终沿用锁定的原比例，不累积比例漂移。这里只调整裁剪框，不缩放图像内容。

设置保存在当前 Windows 用户的 `%LOCALAPPDATA%\CFDImageCropper\saved_region.json`，不会写入图片文件夹。更新或移动 EXE 不影响该设置；复制 EXE 到另一台电脑时不会自动携带该设置。

## 裁剪规则

- 仅处理所选目录当前层的 `.jpg`、`.jpeg`、`.png`，扩展名不区分大小写；不遍历子文件夹。
- 文件名自然排序，例如 `1.png`、`2.png`、`10.png`。
- 所有图片使用同一组原始整数像素坐标 `(left, top, right, bottom)`；右、下边界不包含在裁剪区域内。输出宽度为 `right-left`，高度为 `bottom-top`。
- 图片预览等比缩小，不放大。选区坐标使用实际显示宽高分别换算、四舍五入至最近的原图像素边界；窗口缩放不会改变已确定的原图选区。
- 不识别图像内容，不自动拉伸、旋转或调整后续图片；对含 EXIF 方向信息的照片也使用原始像素排列，适用于仿真导出图片。
- 开始时先检查尺寸，尺寸不同或无法读取的文件跳过；读取像素或保存失败也会记录，继续处理后续图片。完成窗口列出所有异常文件及原因，可选中复制。
- 第一张损坏时提示并采用自然顺序中的第一张可读图片作为基准，坏图片仍会在批量结果中报告。
- 逐张读取、裁剪和释放，后台执行时界面保持响应。任务进行中禁止切换文件夹、重复启动和关闭程序，以免中断保存。
- 保留原文件名和格式。PNG 无损保存（包含透明度）；JPG 裁剪后会重新编码，使用质量 95、无色度抽样，因此文件大小与原图不同。所有结果的**像素尺寸**一致，不保证磁盘文件字节数一致。
- 不复制可能包含旧尺寸、方向或原图缩略图的 EXIF 元数据；保留可用的 ICC 色彩配置和 DPI。

## 生成 GIF 动图

- 裁剪完成后，点击 **用裁剪结果生成 GIF**，直接合成本次成功裁剪的图片。
- 或在主界面点击 **图片转 GIF**，选择一个已有 JPG / JPEG / PNG 图片文件夹。此入口合成所选文件夹中的图片，不套用主界面选框。
- 至少需要 2 张可读取且尺寸相同的图片，按文件名自然顺序逐帧播放。异常图片跳过并报告。
- 每帧时长默认 **100 毫秒**（每秒 10 帧）；可输入 20～10000 毫秒，按 GIF 的 10 毫秒精度取整。
- 输出宽度默认 **960 像素**，等比缩小且不放大；输入 **0** 保持原尺寸。
- 循环播放，输出到所选图片文件夹的 `动画.gif`，已有同名文件时使用 `动画_2.gif` 等名称，不覆盖旧文件。
- GIF 每帧最多 256 色，渐变色可能有色差，透明区域合成为白底。GIF 导出单独调整展示尺寸，原图与裁剪结果不变。
- 逐帧编码、后台运行，不将整批图片加载进内存。不足 2 张有效帧或任务失败时清理本次未完成的 GIF。

## 从源码运行

建议使用 Windows 64 位 Python 3.12 或更新版本（需含 Tkinter）。在项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

安装依赖时需要网络，之后程序运行完全离线。

## 打包 EXE

在已安装运行依赖的环境下：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name "批量图片裁剪工具" main.py
```

生成文件：`dist\批量图片裁剪工具.exe`。`--windowed` 避免黑色命令行窗口，`--onefile` 将运行依赖打包进一个 EXE。单文件版首次启动需要短暂解压到临时目录。

如更重视启动速度，可以将 `--onefile` 换为 `--onedir`；此时需要保留整个输出目录。默认交付单文件版。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

测试使用临时目录生成图片，不读取或修改用户的仿真图片。涵盖：自然排序、100 张 PNG 裁剪尺寸与像素一致性、原文件 SHA-256 不变、4K JPG/JPEG、尺寸不同、坏图片、重复输出目录、PNG 透明度、显示缩放与坐标换算、GUI 拖选、窗口缩放及预览。

## 文件

- `main.py`：裁剪逻辑和桌面界面。
- `gif_export.py`：逐帧 GIF 编码。
- `requirements.txt`：唯一运行依赖 Pillow（Tkinter 随标准 Windows Python 安装）。
- `test_cropper.py`：验收测试，不需要随 EXE 分发。
- `test_gif.py`：GIF 帧顺序、时长、尺寸、异常处理及界面流程测试。
- `dist/批量图片裁剪工具.exe`：打包成品。

当前构建环境：Windows 64 位、Python 3.14.3、Pillow 12.3.0、PyInstaller 6.22.3。
